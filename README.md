# Ugeseddel

Ugentlig timeseddel til telefonen (iPhone og Android), mandag–søndag.

**Åbn appen:** https://kackbeam.github.io/ugeseddel/

- iPhone: åbn linket i Safari → Del-knappen → **Føj til hjemmeskærm**
- Android: åbn linket i Chrome → **Installér app**

Alle timer gemmes kun lokalt på den enkelte telefon.

# Opgaver

Opgavestyring til chef og medarbejdere. Chefen opretter opgaver med beskrivelse, adresse, kunde, LER, tegninger og billeder.
Folkene ser opgaverne, starter og afslutter dem (dato og klokkeslæt gemmes) og tilføjer noter og billeder.

**Åbn appen:** https://kackbeam.github.io/ugeseddel/opgaver/

Data deles mellem alle via Firebase. Første gang skal det sættes op: se [opgaver/OPSAETNING.md](opgaver/OPSAETNING.md).
