# Ugeseddel

Ugentlig timeseddel til telefonen (iPhone og Android), mandag–fredag.

**Åbn appen:** https://kackbeam.github.io/ugeseddel/

- iPhone: åbn linket i Safari → Del-knappen → **Føj til hjemmeskærm**
- Android: åbn linket i Chrome → **Installér app**

Alle timer gemmes kun lokalt på den enkelte telefon.
